# Python Escape Room 🐍

لعبة صفية تفاعلية بالعربية للطلاب 13–16 سنة، مع خمس غرف ولوحة نتائج للمعلمة.

## تشغيل محلي

1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية في مجلد المشروع.
3. شغّل `pip install -r requirements.txt`.
4. عيّن متغير البيئة `TEACHER_PIN` إلى رمز سري خاص بك (الرمز الافتراضي للتجربة فقط: `2468`).
5. شغّل `streamlit run app.py`.

## نشر برابط واحد

1. ارفع ملفات `app.py` و`requirements.txt` إلى مستودع GitHub خاص أو عام (بدون قاعدة البيانات).
2. افتح https://share.streamlit.io/ وانشر تطبيقًا جديدًا من المستودع، مع `app.py` كملف رئيسي.
3. من إعدادات Secrets للتطبيق أضف `TEACHER_PIN = "رمز-سري-قوي"`، ثم عدّل سطر PIN في التطبيق ليقرأ أيضًا `st.secrets` أو اضبط متغير البيئة في بيئة الاستضافة. الأفضل استخدام متغير البيئة عند استضافة التطبيق على خادم خاص.
4. شارك رابط التطبيق مع الفرق. المعلمة تختار «لوحة المعلمة» وتدخل الرمز.

**تنبيه مهم:** SQLite على استضافة Streamlit Community Cloud ليس تخزينًا دائمًا موثوقًا؛ يمكن أن تُفقد النتائج عند إعادة تشغيل التطبيق أو إعادة نشره، وقد تختلف البيانات بين نسخ التشغيل. للتطبيق الصفي الحقيقي متعدد الأجهزة، استخدم خادمًا دائمًا مع قرص ثابت، أو استبدل SQLite بقاعدة بيانات مُدارة مثل PostgreSQL/Supabase. على شبكة الصف، يمكن تشغيل التطبيق على جهاز المعلمة ومشاركة عنوانه المحلي مع الطلاب المتصلين بنفس الشبكة. يجب أن يسمح الجدار الناري بالمنفذ 8501.

## طريقة اللعب

- كل فريق يختار اسمًا وكلمة سر، ويستخدمهما للعودة إلى تقدمه.
- يشغّل الفريق الكود في محرّر Python مستقل، ثم يدخل الناتج.
- الإجابة الصحيحة تساوي 20 نقطة؛ استخدام تلميح يخفض مكافأة الغرفة إلى 15 نقطة.
- النتائج تظهر للمعلمة بعد الضغط على «تحديث النتائج».
- لا يتم تنفيذ كود يكتبه الطلاب على خادم اللعبة.

## مدة الحصة المقترحة

5 دقائق شرح + 5 غرف × 9 دقائق تقريبًا + 10 دقائق مراجعة وتتويج.

## ملاحظة خصوصية

استخدم أسماء فرق غير شخصية. لا تجمع أسماء الطلاب الكاملة. غيّر رمز المعلمة قبل مشاركة الرابط.
